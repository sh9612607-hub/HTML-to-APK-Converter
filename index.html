💡 How to Build APK:
1. Click Generate Android Project to download the ZIP.
2. Extract the ZIP on your PC.
3. Open Android Studio and select File > Open on the extracted folder.
4. Let Gradle sync, then click Build > Build Bundle(s) / APK(s) > Build APK(s).

⚡ Native Android JavaScript Bridge (`AndroidBridge`)

Your web app can directly call native Android hardware and OS features using the global window.AndroidBridge object:

// 1. Show Native Android Toast Message if (window.AndroidBridge) { AndroidBridge.showToast("Order placed successfully! 🎉"); } // 2. Trigger Haptic Vibration (milliseconds) if (window.AndroidBridge) { AndroidBridge.vibrate(100); } // 3. Open Native Android Share Sheet if (window.AndroidBridge) { AndroidBridge.shareText("Check out this amazing app!", "Share App"); } // 4. Copy to System Clipboard if (window.AndroidBridge) { AndroidBridge.copyToClipboard("COUPON-2026"); } // 5. Open External Browser / Intent if (window.AndroidBridge) { AndroidBridge.openExternal("https://wa.me/1234567890"); } // 6. Get App Version var version = window.AndroidBridge ? AndroidBridge.getAppVersion() : "1.0.0";

☁️ Free Cloud APK Compilation via GitHub Actions

Don't have a fast computer or Android Studio installed? Every generated ZIP automatically contains a ready-to-run GitHub Actions workflow: .github/workflows/build-apk.yml.

Easy 3-Step Cloud Build:
  1. Download the generated Android project ZIP and extract it.
  2. Create a free repository on GitHub and upload/push the files.
  3. Go to the Actions tab on your repository. The workflow will automatically compile your project and provide a download link for app-debug.apk!

🔐 Android Keystore & Google Play Release Helper

To publish your APK or AAB on Google Play Store, you need a signed release key. Run this standard command in your terminal:

keytool -genkey -v -keystore release-key.jks -alias my-app-key -keyalg RSA -keysize 2048 -validity 10000

Remember your keystore password and alias. You will use them in Android Studio under Build > Generate Signed Bundle / APK.
